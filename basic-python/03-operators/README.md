# Python Operators ⚙️

This folder introduces operators used to perform operations and make decisions in Python.

Operators help programs think logically.

---

## 🧮 Types of Operators Covered

This folder covers:
- Arithmetic operators
- Comparison operators
- Logical operators

---

## ➕ Arithmetic Operators

Arithmetic operators are used for calculations.

Examples:
- `+` addition
- `-` subtraction
- `*` multiplication
- `/` division

These are used in calculators and math-based programs.

---

## 🔍 Comparison Operators

Comparison operators compare values and return `True` or `False`.

Examples:
- `==` equal to
- `!=` not equal to
- `>` greater than
- `<` less than
- `>=` greater than or equal to
- `<=` less than or equal to

These operators are commonly used inside conditions.

---

## 🧠 Logical Operators (`and`, `or`)

Logical operators are used to **combine conditions**.

They help answer questions like:
- Is this true AND that true?
- Is this true OR that true?

---

### `and` Operator

The `and` operator returns `True` only if **both conditions are true**.

Example idea:
> Both numbers are positive AND greater than zero.

---

### `or` Operator

The `or` operator returns `True` if **at least one condition is true**.

Example idea:
> A number is negative OR zero.
