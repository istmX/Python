# Basic Python 🐍

Welcome to the **Basic Python** learning path — the first stage of
the ISTMX Python learning journey.

This stage takes you from **absolute zero** to a solid foundation
in Python. Every topic builds on the previous one, so follow the
folders in order.

---

## 🎯 What This Stage Covers

By the end of this stage, you will understand:

- How Python works and how it reads code
- Input, output, variables, and strings
- Data types and operators
- Conditions and decision making
- Loops and repetition
- Functions and code organization
- Lambda functions and scope
- Recursion
- Comprehensions
- Functional tools: `map()`, `filter()`, `reduce()`
- Object-Oriented Programming (OOP)
- Modules and packages
- Exception handling
- File handling
- Iterators and generators
- Useful built-in functions

## ▶️ How to Learn From This Stage

1. **Read each folder's README first** — it explains the concepts
   and lists every file.
2. **Run every example** — learning by doing works best:
   ```bash
   python filename.py
   ```
3. **Try the practice exercises** at the end of each README.
4. **Build the mini projects** — they combine everything you learned.
5. **Do not rush** — strong basics make advanced topics much easier.

You will be ready for the **Intermediate Python** stage:
virtual environments, `pip`, JSON, APIs, logging, and testing.
