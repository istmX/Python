# Python Data Types 🧩

This folder introduces **data types in Python**.

Data types tell Python **what kind of value** a variable is holding  
(text, number, or true/false).

Understanding data types is very important before moving to:
- operators
- conditions
- loops

---

## 🧠 What Are Data Types?

A **data type** defines the type of data stored in a variable.

In simple words:
- text → string
- numbers → int or float
- true / false → boolean

Python automatically understands data types,  
but **you must understand them as a programmer**.

---

## 🧵 Strings (`01-strings.py`)

Strings are used to store **text**.

Anything written inside quotes is a string.

Examples:
- names
- messages
- user input

Strings are mainly used for:
- interacting with users
- displaying output
- formatting messages

This file focuses on:
- basic string operations
- working with user input
- understanding how text behaves in Python

---

## 🔢 Numbers (`02-numbers.py`)

Numbers are used to store numeric values.

Examples:
- age
- marks
- year
- count

Python mainly uses:
- `int` → whole numbers
- `float` → decimal numbers

Numbers are used for:
- calculations
- totals
- real-world values like age or price

---

## ✅ Boolean Values (`03-boolean.py`)

A **boolean** represents only two values:
- `True`
- `False`

Booleans usually come from:
- comparisons
- checks

Examples of ideas:
- Is the user adult?
- Is a value correct?

This file helps you understand:
- what True and False mean
- how Python produces boolean values

Booleans are the **foundation of conditions and logic**.

---

## 🔍 Type Checking (`04-type_checks.py`)

Sometimes you need to know **what type of value** a variable holds.

Python provides the `type()` function for this.

This file helps you understand:
- how Python decides data types
- the difference between string input and numeric input
- why type checking is useful while learning

This builds clarity before moving to operators and conditions.
