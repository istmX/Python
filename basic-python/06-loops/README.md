# Loops in Python 🔁

This folder introduces **loops in Python**.

Loops are used to **repeat a block of code** multiple times
without writing the same code again and again.

---

## 🧠 Why Loops Are Important

Loops help when:
- repeating tasks
- working with ranges of numbers
- automating repetitive work

Without loops, programs become long and messy.

---

## 📘 What You Will Learn

- `for` loops
- `while` loops
- using `range()`
- repetition logic
- loop control statements (`break`, `continue`)
- beginner-friendly loop projects
