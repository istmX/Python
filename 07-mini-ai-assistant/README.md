# First Python Project – Mini AI Assistant 🤖

This project is designed as a **first complete Python project** for beginners.

The purpose of this project is to show how small Python concepts, when combined together, can create an interactive and meaningful program.

This is not a real AI.  
It is a **logic-based assistant** built using beginner-level Python concepts.

---

## 🎯 Why This Project Exists

Many beginners learn Python topics one by one, but struggle to understand:
- how everything connects
- how a real program flows
- how user interaction works

This project solves that problem.

Instead of learning concepts in isolation, this project **combines them** into one program so learners can see how Python is actually used.

---

## 🧠 Concepts Used (Nothing Advanced)

Only the following concepts are used:

- `print()` and `input()`
- Variables
- Strings
- Conditional statements (`if`, `elif`, `else`)
- Comparison operators
- Loops (`for`, `while`)
- Basic logic building

No functions, no files, no advanced features are used on purpose.

---

## 🧩 How the Program Works (Step by Step)

1. The assistant introduces itself
2. It asks for the user’s name and age
3. It responds differently based on age
4. A menu is shown with multiple options
5. The user selects an option
6. The assistant performs the selected task
7. The menu keeps appearing until the user chooses to exit

This flow teaches how **real programs run continuously**, not just once.

---

## 📋 Features Included

The assistant can:
1. Perform simple calculations
2. Generate multiplication tables
3. Check whether a number is even or odd
4. Run a number guessing game
5. Exit the program politely

Each feature uses logic that beginners already understand.

---

## 🔁 Why the Menu Uses a Loop

In real applications, programs do not stop after one action.

A loop is used so:
- the menu keeps showing again and again
- the user can try multiple options
- the program only exits when the user chooses to

This introduces the idea of **program control flow** in a simple way.

---

## ▶️ How to Run the Project

Make sure Python is installed.

From inside this folder, run:
python main.py


Follow the instructions shown on the screen.
