# Loops in Python

This folder introduces loops in Python.  
Loops are used to repeat a block of code multiple times.

---

## 📘 What You Will Learn

- for loops  
- while loops  
- using range with loops  
- repeating logic using loops  
- loop control statements (`break`, `continue`)  
- basic loop-based programs  

---

## 📁 Files in This Folder

- `01-for-loop.py`  
  Basic for loop example  

- `02-while-loop.py`  
  Basic while loop example  

- `03-range-variations.py`  
  Different ways to use range()  

- `04-break-continue.py`  
  Using `break` and `continue` in loops  

- `project-multiplication-table.py`  
  Generate a multiplication table using loops  

- `project-guess-number.py`  
  A simple number guessing game
