# GEN AI

Hey there! Welcome to the world of Generative AI.

Let's be honest. We've all used AI at least once, whether it was asking ChatGPT a random question at 2 AM, fixing a bug in our code, writing an assignment, or asking an AI why our code isn't working even though we swear we did everything right.

And if you're reading this repository, there's a good chance you've used AI too. Maybe you're curious about how it actually works. Maybe you're a developer who wants to build AI-powered applications. Or maybe you just want to understand what's happening behind that chat box instead of blindly trusting whatever it says.

Well, you're in the right place.

And yes, I know I've already written a lot just to introduce a topic. Let's consider that our first lesson in generating text.

## So, what are we going to learn?

We're not going to jump straight into writing code, copy an API request, and pretend we understand everything. We'll start with the basics, build our understanding step by step, and eventually use what we've learned to create actual AI-powered applications.

Here's the roadmap.

| No. | Topic | What you'll learn |
|---|---|---|
| 01 | Introduction to Generative AI | What GenAI is, where we use it, and how it differs from traditional AI. |
| 02 | Understanding LLMs | What Large Language Models are and how they generate responses. |
| 03 | Tokens and Context Windows | How models process text, what tokens are, and why context limits matter. |
| 04 | Prompts and Messages | System instructions, user messages, assistant responses, and writing better prompts. |
| 05 | Memory and Conversation History | How AI applications maintain conversation context and manage memory. |
| 06 | APIs and SDKs | What APIs and Software Development Kits are, why they exist, and how developers use them. |
| 07 | Your First LLM API Call | Connect Python to a model using a provider's SDK and generate your first response. |
| 08 | Handling API Errors | Authentication failures, rate limits, quotas, timeouts, and retries. |
| 09 | Model Providers | Explore Google, Groq, Mistral, DeepSeek, Hugging Face, and OpenRouter. |
| 10 | Structured Outputs and Tool Calling | Get structured responses and let models request actions through tools. |
| 11 | Embeddings and Vector Search | Understand how text can be represented as vectors and searched by similarity. |
| 12 | Retrieval-Augmented Generation (RAG) | Give AI applications relevant external information to work with. |
| 13 | Introduction to LangChain | Learn how a framework simplifies building LLM applications. |
| 14 | Introduction to LangGraph | Build stateful workflows and more advanced agentic applications. |
| 15 | Projects | Put everything together and build practical AI applications. |

This is our planned learning path. We'll expand each topic into its own folder with individual explanations, code examples, exercises, and projects as we progress.

## A few things before we begin

You don't need to know everything about AI to start learning Generative AI.

You should, however, be comfortable with Python fundamentals, functions, modules, and basic file handling. Knowing how to install packages and work with environment variables will help when we start making API requests.

We'll explain unfamiliar concepts along the way instead of assuming you already know them.

We'll also learn to work with AI responsibly. Models can make mistakes, API access can have limits, and some services require payment depending on their pricing and usage policies. We'll cover those details when they become relevant.

## One last thing

The goal isn't to memorize a bunch of libraries or become someone who can only follow tutorials.

The goal is to understand what's happening, know why we're doing something, and eventually build things of your own.

So grab your curiosity, bring your questions, and don't worry if something doesn't make sense immediately. That's part of learning.

Let's get started.
